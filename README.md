# Eye-Protector

A simple tool to remind you to take care of your eyes and take regular breaks. Perfect for those who spend long hours in front of a screen!

## Features

- Reminds you to take breaks and relax your eyes.
- Easy installation and uninstallation.
- doesn't keep any useless file after unistall.
- System-wide notifications to encourage eye care.
- even terminal starts talking!

## Installation

To install **Eye Protector**, follow these steps:

1. Download the repository to your local machine.
2. Open a terminal and run these commands:
   ```bash
   cd ~/Downloads/eyeProtector
   chmod +x Install.sh
   ./Install.sh
   ```
3. Its installed!

## Uninstallation 

To uninstall **Eye Protector**, its so simple:

1. Open a terminal and run these commands:
   ```bash
   cd ~/Downloads/eyeProtector
   chmod +x Uninstall.sh
   ./Uninstall.sh
   ```
2. done!
